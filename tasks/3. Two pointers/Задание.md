# Задача 3: Valid Palindrome

## Условие

Дана строка `s`.

Нужно вернуть `True`, если строка является палиндромом, и `False`, если нет.

Палиндром — это строка, которая читается одинаково слева направо и справа налево.

При проверке нужно учитывать только буквы и цифры.

Регистр букв не важен.

Пробелы, знаки препинания и другие символы нужно игнорировать.

## Примеры

### Пример 1

```python
s = "A man, a plan, a canal: Panama"
# Ответ: True
